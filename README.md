## 🛠️ Tools Used

* **Microsoft Power BI Desktop:** Used for the entire report-building lifecycle.
* **Power Query (M):** For data extraction, transformation, and loading (ETL).
* **DAX (Data Analysis Expressions):** For creating complex measures and calculated columns.
* **Data Modeling:** Designing relational models to connect multiple data sources.

## 🚀 How to View These Projects

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/forkanaminshaon/Power-BI-Projects.git](https://github.com/forkanaminshaon/Power-BI-Projects.git)
    ```
2.  **Download the Files:**
    Alternatively, you can download individual `.pbix` files directly from the repository.
3.  **Open the Files:**
    You must have [Microsoft Power BI Desktop](https://powerbi.microsoft.com/en-us/desktop/) (a free application) installed on your Windows machine to open and interact with the `.pbix` files.
